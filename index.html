THE BASICS

Five things to learn first

These concepts are enough to start writing simple Python programs.

01

Variables

Variables store information that your program can use later.

name = "Alex"
age = 20
02

Data Types

Python has different types of values such as text, numbers, and true/false values.

name = "Alex"   # string
age = 20        # integer
student = True  # boolean
03

Conditions

An if statement lets your program make a decision.

age = 20

if age >= 18:
    print("Adult")
04

Loops

Loops repeat instructions without writing the same code many times.

for number in range(5):
    print(number)
05

Functions

Functions group instructions so you can reuse them in your program.

def greet(name):
    print("Hello", name)

greet("Alex")
