15 QUICK LESSONS

Learn Python step by step.

Start with simple commands, then move toward programs that make decisions, repeat tasks, store data, and perform calculations.

01

What is Python?

Python is a beginner-friendly language used for websites, automation, data, AI, and many other projects.

print("Hello, Python!")
02

Print Output

The print() function displays information on the screen.

print("Welcome!")
print(2026)
03

Variables

Variables store values that your program can use later.

name = "Alex"
age = 20
print(name)
04

Data Types

Python uses strings, integers, floats, and booleans.

name = "Alex"
age = 20
price = 99.50
student = True
05

User Input

The input() function lets a program ask the user for information.

name = input("Your name: ")
print("Hello", name)
06

Operators

Operators perform calculations and compare values.

a = 10
b = 3
print(a + b)
print(a > b)
07

If Statements

Use if when your program needs to check a condition.

age = 20
if age >= 18:
    print("Adult")
08

If / Else

Use else when you need another action if the condition is false.

age = 16
if age >= 18:
    print("Adult")
else:
    print("Minor")
09

Elif

elif checks another condition when the previous condition was false.

score = 85
if score >= 90:
    print("Excellent")
elif score >= 75:
    print("Passed")
else:
    print("Try again")
10

For Loops

A for loop repeats code for each item in a sequence.

for number in range(5):
    print(number)
11

While Loops

A while loop continues while its condition is true.

count = 1
while count <= 5:
    print(count)
    count += 1
12

Lists

Lists store multiple values in one variable.

fruits = ["Apple", "Mango", "Banana"]
print(fruits[0])
print(len(fruits))
13

Dictionaries

Dictionaries store information using key-value pairs.

student = {
    "name": "Alex",
    "age": 20
}
print(student["name"])
14

Functions

Functions group reusable instructions into one block of code.

def greet(name):
    print("Hello", name)

greet("Alex")
15

Mini Project: Calculator

Combine variables, input, operators, and output to build a simple calculator.

a = float(input("First number: "))
b = float(input("Second number: "))
print("Sum:", a + b)
print("Product:", a * b)
